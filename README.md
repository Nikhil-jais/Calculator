# 🧮 Calculator

A simple and responsive calculator built using HTML, CSS, and JavaScript.

## ✨ Features

- Addition
- Subtraction
- Multiplication
- Division
- Percentage
- Decimal calculations
- Clear button
- Delete button
- Responsive design
- Modern user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📱 Responsive Design

The calculator is designed to work on different screen sizes, including:

- 💻 Desktop
- 📱 Mobile
- 📲 Tablet

## 🚀 How to Use

1. Open the calculator.
2. Enter numbers using the buttons.
3. Select an operation.
4. Press `=` to calculate the result.
5. Use `C` to clear the display.
6. Use `⌫` to delete the last character.
